# Fracttal PRM

Partner Relationship Management system for onboarding and managing Fracttal system resellers and implementation partners.

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | FastAPI (Python 3.11+) |
| Frontend | React + Vite |
| Database | PostgreSQL (Railway managed) |
| Hosting | Railway |
| CI/CD | GitHub Actions |
